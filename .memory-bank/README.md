# Memory Bank

Long-term, project-level memory for planning, progress tracking, and decisions.

## Core Files

- `STATUS.md` current project state and key constraints.
- `plan.md` active plan overview.
- `checklist.md` open execution checklist.
- `RESEARCH.md` supporting research notes and references.
- `BACKLOG.md` ideas and deferred work.
- `progress.md` append-only progress log.

## Optional Expansion

Add topical folders as needed:

- `notes/`
- `plans/`
- `experiments/`
- `reports/`
- `codebase/`
